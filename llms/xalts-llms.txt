# Xalts

> Xalts (Tokuten Pte Ltd) is an Accel-backed fintech that builds an AI agent
> platform for corporate treasury and finance teams — a "Copilot for Treasury
> & Finance". Task-specific agents automate trade finance (guarantees, trade
> payments, documentary credit and collections), liquidity management, and
> revenue operations, integrating with ERPs, accounting systems, payment
> processors, and banks via its Omni Connect Protocol (multi-bank
> connectivity through a single API).

Xalts does not currently publish a public developer portal, API
documentation, or machine-readable API specifications. Its Omni Connect
Protocol bank-connectivity API is offered to enterprise customers without
public docs. This file was generated by API Evangelist from the company's
public website and the artifacts in this repository.
